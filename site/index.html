      About this page

      A single-file interactive report built from the Nobel Prize open dataset (1901–2019), the same data used in the accompanying notebook analysis. Everything runs in your browser: no server, no tracking, no external libraries.

      How the data was cleaned

      • Organisations had no gender in the raw data; they are labelled Organization, not left blank.
      • Age = award year − birth year, parsed manually because many dates use 00-00.
      • Historical countries (USSR, Prussia, Persia, British India…) mapped to modern names.
      • Institution and affiliation country are parsed from the affiliation string.
      • Prize values use the inflation-adjusted USD column.

      Read with care

      • Affiliation is missing for 253 of 950 records, so migration rates cover 697 records only.
      • Birth country is missing for 27 records (mostly organisations).
      • Country borders are modern, so pre-1991 laureates are re-attributed.
      • “Women” is based on the recorded gender field; organisations are excluded from that share.
      Data: Nobel Prize API via the public laureates dataset · Analysis and design: Nobel Atlas · Built as a standalone HTML file — works offline.
